Pemulihan Otomatis (Auto-Recovery)
Aktifkan Pemulihan Mandiri

Jika audio mati total melewati batas waktu, Agent akan mencoba me-restart sumber audio di OBS secara paksa (Restart Source) untuk memulihkannya.

Waktu Tunggu Pemulihan (Detik)

Durasi Agent menunggu dalam keadaan BAHAYA sebelum mengeksekusi pemulihan paksa. Disarankan minimal 10 detik agar tidak bereaksi terlalu sensitif terhadap jeda diam normal.

Mode Pemulihan Ekstrem (Restart OBS)

Jika restart source audio gagal, Agent berwenang untuk mematikan dan membuka ulang seluruh aplikasi OBS Studio secara paksa.
